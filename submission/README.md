# Submission package

- `Unilog_Product_Intelligence_Pitch.pptx` — the pitch deck (20 slides). The
  official Google Slides template could not be downloaded in this sandboxed
  build environment (network egress to `docs.google.com` is blocked by the
  proxy — verified, not assumed). This deck mirrors the required section
  structure with real project content; **copy these sections into the
  official template before final submission.**
- `build_deck.js` — regenerates the deck (`npm install && node build_deck.js`).
  Kept as source so the deck can be edited/rebuilt rather than hand-patched.
- Speaker notes on slides 5, 14, and 15 carry extra technical detail for
  presenting live.

See `docs/demo-script.md` for the live-demo walkthrough and
`docs/judge-cheatsheet.md` for a criterion → evidence map.
